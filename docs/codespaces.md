# Запуск в GitHub Codespaces

Codespaces даёт бесплатную машину с Node.js и публичный HTTPS-адрес — этого достаточно, чтобы
играть с друзьями и чтобы Long Story Short мог встроить лист (после добавления домена в белый
список).

## 1. Создать Codespace

1. Загрузите проект в репозиторий на GitHub.
2. На странице репозитория: **Code → Codespaces → Create codespace on main**.
3. Дождитесь, пока `postCreateCommand` выполнит `npm install`.

Конфигурация лежит в `.devcontainer/devcontainer.json`: проброшены порты **5173** (Vite) и
**8787** (сервер комнат).

## 2. Режим разработки

В терминале Codespace:

```bash
npm run dev
```

Затем откройте вкладку **Ports** (внизу рядом с Terminal):

1. Найдите порт **5173**.
2. Правый клик → **Port Visibility → Public**.
3. Скопируйте адрес вида `https://<имя>-5173.app.github.dev` и откройте его.

Этот адрес уже можно отправлять игрокам. Vite проксирует `/api` и `/ws` на сервер комнат
(8787) внутри Codespace, поэтому отдельный публичный порт для 8787 в dev-режиме не нужен.

## 3. Режим «как в бою» (один порт)

Для игры удобнее собранная версия: один порт, без HMR и лишних запросов.

```bash
npm run codespace
```

Скрипт собирает клиент и запускает сервер на **8787**. Откройте **Ports → 8787 → Public** и
используйте адрес `https://<имя>-8787.app.github.dev`.

## 4. Пригласить игроков

1. Создайте комнату в приложении и передайте код.
2. Игроки открывают публичный URL Codespace → «Комнаты» → «Войти по коду».
3. Для игры через Radmin VPN Codespaces не нужен, но он удобен, когда у всех разные сети.

## 5. Ограничения бесплатного тарифа

- GitHub Free: **120 core-hours** и **15 GB-month** в месяц; на 2-ядерной машине это примерно
  **60 часов** работы Codespace ([документация GitHub](https://docs.github.com/en/billing/managing-billing-for-your-products/about-billing-for-github-codespaces)).
- Codespace останавливается после простоя (по умолчанию 30 минут). После остановки публичный
  URL перестаёт отвечать, пока Codespace не запустят снова.
- Файлы Codespace сохраняются между остановками и запусками, пока Codespace существует:
  `server/data/rooms.json` с комнатами не теряется. При удалении Codespace всё пропадёт.
- Порт, открытый как Public, доступен любому, кто знает URL. Комнаты защищены кодом и ключом
  Мастера, но не выкладывайте ссылку в открытый доступ.

## 6. Встраивание листа LSS

Origin Codespace выглядит так: `https://<имя>-8787.app.github.dev` (или `-5173` в dev-режиме).
Он стабилен, пока Codespace существует. Попросите добавить именно его в белый список LSS:
`@shakusky` в Telegram, `shakusky.lss` в Discord или сообщения сообщества VK. Если Codespace
пересоздать, имя и адрес изменятся — домен придётся добавлять заново.

После добавления откройте в комнате вкладку **Лист → Открыть лист LSS**: iframe загрузится, а
броски из листа пойдут в чат комнаты.

## Если что-то не открывается

- Убедитесь, что порт действительно **Public**, а не Private.
- Перезапустите `npm run dev` (или `npm run codespace`) после изменения портов.
- Проверьте, что Codespace не остановлен (индикатор в левом нижнем углу VS Code).
- Внутри Codespace `http://localhost:5173` работает всегда; публичный URL — только при Public
  порте.
